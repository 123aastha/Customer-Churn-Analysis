Telco Customer Churn – Exploratory Data Analysis (EDA)

This repository contains a complete Exploratory Data Analysis (EDA) project on the Telco Customer Churn dataset. The aim of the project is to identify key factors influencing customer churn and generate insights that can support retention strategies.

📂 Files in This Repository
1. Raw Dataset (CSV)

Contains the original telecom customer churn data used for analysis.

2. EDA Notebook (Python / Jupyter Notebook)

Includes all data preprocessing, visualizations, countplots, stacked charts, and code-based insights.

3. Summary Report (PDF)

A clean written summary covering:

Key findings

Important churn patterns

Percentage-based insights

Final recommendations

📊 Project Overview

This EDA explores:

Customer demographics

Internet & service usage

Contract and billing patterns

Payment behavior

Churn distribution and influencing factors

Multiple visualizations (countplots, stacked bar charts, percentage charts) were used to understand how different variables impact churn.

🔍 Key Insights

Month-to-month customers show the highest churn (~45–50%).

Customers using electronic checks churn the most (~40–45%).

Fiber-optic users churn significantly more than DSL users.

Absence of add-on services like security, backup, and tech support leads to 25–35% churn.

Senior citizens and high-bill customers show higher churn tendencies.
